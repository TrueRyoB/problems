## human slop

存在し得るアメリカ人のファーストネームを、重複なく $N$ 人分出力してください。

### 制約

#### 入力
- $1 \leq N \leq 10^5$

#### 出力
- 出力はちょうど $N$ 行でなければならない
- 各行は独立に判定され、以下をすべて満たす場合に限り受理される
  - 正規表現 `^[A-Z][a-z]+$` に一致し、長さが $2$ 以上 $15$ 以下である
  - それ以前のどの行とも相異なる（大文字小文字は同一視する。重複は2回目以降が不受理）
  - アメリカ人のファーストネームとして妥当であるとジャッジが判断する
- 妥当性の判定は決定的だが、判定基準の詳細は非公開である
- ジャッジは受理された行数が一定数以上であるとき `AC`、満たないとき `WA` とする

### 入力

入力として $N$ が1行で与えられる。

```
N
```

### 出力

存在し得るアメリカ人のファーストネームを、1行に1つずつ、ちょうど $N$ 行出力せよ。

### 判定例

各行に対する受理/不受理の例:

| 出力行 | 判定 | 備考 |
|---|---|---|
| `James` | 受理 | |
| `Kaylenna` | 受理 | 実在の記録がなくても、名前として妥当であれば受理される |
| `Xylophone` | 不受理 | 英単語であって名前ではない |
| `Abcde` | 不受理 | 実在の記録があっても、名前として不自然であれば受理されない |
| `Nanana` | 不受理 | |
| `Xqzvbn` | 不受理 | |
| `mcDonald` | 不受理 | 形式違反 |
